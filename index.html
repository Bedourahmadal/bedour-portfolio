BeautyMR

AI-Powered Mixed Reality Beauty Assistantمساعدة تجميل بالواقع المختلط مدعومة بالذكاء الاصطناعي

An intelligent Mixed Reality beauty assistant for Meta Quest 3. It enables real-time facial analysis and virtual makeup using on-device AI and spatial computing. Unlike 2D beauty apps, BeautyMR builds a live 3D facial map so virtual cosmetics stay aligned with facial movement and geometry — with all AI inference running directly on the device.مساعدة تجميل ذكية بالواقع المختلط لجهاز Meta Quest 3. تتيح تحليل الوجه وتجربة المكياج الافتراضي في الوقت الفعلي باستخدام ذكاء اصطناعي يعمل على الجهاز والحوسبة المكانية. وخلافًا لتطبيقات التجميل ثنائية الأبعاد، تبني خريطة ثلاثية الأبعاد حيّة للوجه لتبقى المستحضرات متوافقة مع حركة الوجه وهندسته — مع تنفيذ كل الاستدلالات مباشرةً على الجهاز.
